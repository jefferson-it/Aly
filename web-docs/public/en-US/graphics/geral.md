# Graphical User Interface (GUI) in Aly

Aly features a native abstract GUI toolkit that compiles and executes across multiple platform backends.

---

## 1. Unified Interface Abstraction

Instead of writing platform-specific UI code, Aly developers construct layouts using standard OOP GUI classes (`Window`, `Button`, `Label`, `Input`). Under the hood, these layouts map to widgets generated by the active platform backend.

```aly
const win = new Window("Title", 400, 300)
const btn = new Button("Press")
win.insert(btn)
win.loop()
```

---

## 2. Supported Backends

* **FLTK**: The default backend. Highly lightweight and portable.
* **GTK4**: Modern Linux-focused desktop experience.
* **Cocoa**: Native macOS UI components.
* **Qt**: Custom backend placeholder.
* **DOM**: Virtual representation for web compilation.
