# Inteligência Artificial e Machine Learning

> Módulo `ml.*`, `llm.*`, `embed.*`

---

## 🧠 Visão geral

Aly fornece *bindings* para IA/ML sem reimplementar frameworks inteiros.

Atualmente disponíveis:
- `ml.*` — sessões, modelos, tensores e inferência
- `llm.*` — carregamento de modelos GGUF e geração
- `embed.*` — embeddings

Features do Cargo:
- `ai` — habilita `ai-candle`
- `ai-candle` — ML em Rust puro
- `ai-onnx` — ONNX Runtime
- `ai-llama` — bindings para llama.cpp
- `ai-tensorflow` — bindings para libtorch/TensorFlow
- `ai-pytorch` — bindings para libtorch/PyTorch

Compile com:
```bash
cargo build --features ai
```

---

## 🤖 ML Core

| Função Aly | Descrição |
|---|---|
| `ml.create(name, backend)` | Cria sessão (`candle`, `onnx`) |
| `ml.list_sessions()` | Lista sessões |
| `ml.infer(session, model, input)` | Inferência |
| `ml.load_model(name, path, backend)` | Registra modelo |
| `ml.list_models()` | Lista modelos |
| `ml.backend_info()` | Mostra backends disponíveis |
| `ml.help()` | Ajuda do módulo |

Exemplo:
```aly
info = ml.backend_info()
print(info)

sess = ml.create("s1", "candle")
print(sess)

res = ml.infer("s1", "model.bin", "input data")
print(res)
```

## 🦙 LLMs

| Função Aly | Descrição |
|---|---|
| `llm.load_gguf(name, path, context_size)` | Carrega modelo GGUF |
| `llm.generate(model, prompt, max_tokens)` | Gera texto |
| `llm.chat(model, system_prompt, user_prompt)` | Chat multi-turno |

Exemplo:
```aly
llm.load_gguf("llama", "models/llama.gguf", 2048)
resp = llm.generate("llama", "Olá mundo", 256)
print(resp)
```

---

## 📐 Embeddings

| Função Aly | Descrição |
|---|---|
| `embed.create(name, model, dimension)` | Cria modelo de embeddings |
| `embed.encode(model, text, normalize)` | Codifica texto |

---

## 🧩 TensorFlow / PyTorch

Aliases são fornecidos para conveniência:
- `ml.tf_model(name, path)` → `ml.load_model(name, path, "candle")`
- `ml.torch_model(name, path)` → `ml.load_model(name, path, "candle")`

---

## 🛠️ Backend Info

Quando a feature não está habilitada, as funções retornam mensagens informando que o backend está desabilitado em tempo de compilação.

```aly
# Sem feature habilitada
print(ml.backend_info())
# ML backends: candle=disabled onnx=disabled llama=disabled embeddings=disabled
```
